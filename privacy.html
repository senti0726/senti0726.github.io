Privacy policy

Last updated 2026-11-06

This policy covers the Google OAuth app "rclone" registered by senti0726, and this website.

The rclone app

It is a personal tool, used only by its owner to upload their own files to their own Google Drive with rclone. It requests only the drive.file permission, so it can see only files it created itself — never the rest of a Drive.

  • The access token is stored only on the owner's own computer.
  • No Google user data is collected, sold, shared with third parties, or used for advertising or AI training.
  • No data is sent anywhere except between that computer and Google's own servers.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.

This website

A static page on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visits as described in its privacy statement.
